# デザインの基本方針

「旬なもの」は、日本のスーパーで買い物をする人が、今が旬の食材と、おいしいものを選ぶコツをひと目で理解できるデザインにする。

## デザインシステム

Material 3 を土台に、標準の部品と操作を使う。色・文字・イラスト・アプリ名の表現で、温かく親しみやすい雰囲気を作る。

## 判断基準

- 小学生でも使える、やさしいことばと視覚表現にする。
- 買い物中に迷わず食材を見つけ、選び方を確認できるようにする。
- 情報量を絞り、食材の絵と選び方を主役にする。
- 色だけに頼らず、文字・形・配置でも意味を伝える。
- 片手で操作しやすく、押す場所を見分けやすくする。
