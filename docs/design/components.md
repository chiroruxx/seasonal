# 共通部品

Material 3 の部品と操作を基本にする。

## 食材カード

- 食材の全体像を描いたイラストを大きく表示する。
- 絵の下に食材名を表示する。
- 絵と名前で食材を見分けられるよう、情報量を絞る。
- カードをタップして選択できるようにする。
- 背景に surfaceContainerLow、文字に onSurface を使う。

## モーダルボトムシート

- 画面の上に重なり、下から開く。
- 内容を識別できるタイトルと、閉じるボタンを表示する。
- 閉じるボタン・背景タップ・下スワイプで閉じられるようにする。
- 閉じた後も、呼び出し元のスクロール位置を保つ。
- 背景に surfaceContainer、文字に onSurface を使う。

## 操作と読みやすさ

- 片手でも押しやすい操作領域を確保する。
- 文字を大きくしても、名前や説明を欠けさせない。
- 色だけに意味を持たせず、文字・形・配置でも区別する。
