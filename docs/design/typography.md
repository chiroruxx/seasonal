# 文字と言葉

## 文字の使い分け

- 本文・食材名は、読みやすさを優先する。
- 見出しと本文に階層を付け、Material 3 の文字スタイルを基本にする。
- アプリ名だけに丸みのある文字と装飾を使う。本文や食材名には広げない。
- 端末の文字サイズ設定を大きくしても、名前や説明が欠けないようにする。
- 説明の文字は画像に描き込まず、UI のテキストとして表示する。

## 表記

難しい漢字を避け、ひらがな・カタカナを中心にする。「旬」はアプリ名にも使う中心的なことばとして漢字で表記する。

| 用途 | 表記 |
| --- | --- |
| アプリ名 | 旬なもの |
| 今が旬の一覧 | いまが 旬 |
| これから旬になる食材の一覧 | そろそろ 旬 |
| これから旬になる時期の補足 | らいげつから |
| 食材の選び方 | えらびかた |
| 旬の時期 | 旬の じき |

説明は短く区切り、店頭で見るポイントが伝わることばを使う。
