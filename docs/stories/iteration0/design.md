# 画面とデザインの検討

## 合意した方向性

- 一覧を基本画面にし、食材の詳細はモーダルボトムシートで開く。
- 一覧で「いまが 旬」と「そろそろ 旬」を見られるようにする。
- 「そろそろ旬」は、来月から旬になる食材とする。
- 最初は分類の切り替えを設けず、野菜・魚・果物を同じ一覧に表示してみる。
- 食材そのものを描く図鑑寄りの絵と、小学生にもわかるやさしいことばを使う。
- 成分・通知・目標・バッジは設けない。
- デザインシステムは Material 3 を土台にする。
- 配色は C「実りの橙」に近い暖色をベースに進める。具体的な色コードは未確定。

## デザインシステム

### 基本方針

Material 3 を土台に、標準の操作や部品を使う。アプリ独自の表現は、食材の図鑑風イラストと、色・文字・形・余白のテーマ設定を中心に検討する。

Material 3 の採用はデザイン方針として決定済み。UI の実装方式や依存ライブラリは、技術選定で別途決める。

### 次に具体化するルール

- 色：背景、文字、アクセント、「いまが 旬」「そろそろ 旬」の見せ方。
- 文字：書体、大きさ、やさしいことばを使う基準。
- 絵：食材の形や色の再現度、線、質感。
- 形と余白：カードの角、絵の大きさ、要素の間隔、押しやすい操作領域。
- 共通部品：食材カード、セクション見出し、詳細画面の上部と戻る操作。

温かみのある白を背景に、落ち着いた橙をアクセントとして、食材の色を引き立てる方向とする。[配色案とルール](colors.md)を参照。具体的な色や寸法は、ラフで確認して決める。

## 文字と言葉のルール

### アプリ名とロゴ

- 画面上部のアプリ名は[比較案](mockups/branding/name-options.png)の B を採用する。丸みのある文字、茶色寄りの橙、手描き風の下線で絵本のタイトルのように見せる。
- アプリロゴは C の「旬＋葉」のシンボルを使う方向。[ロゴ素材案](mockups/branding/app-logo.svg)として切り出している。
- 本文や食材名には装飾した書体や下線を広げず、読みやすさを優先する。
- ラフの書体は環境依存。ロゴ SVG も文字要素を含むため、本番素材では書体・利用条件を決めて文字の形を固定する。
- Android ランチャーアイコンへの組み込みは未実施。ロゴ素材案をもとに、アダプティブアイコンの領域や各サイズでの見え方を別途調整する。

### 表記

難しい漢字を避け、ひらがな・カタカナを中心にする。ただし「旬」はアプリ名にも使う中心的なことばなので、漢字で表記する。

- 表示例：「いまが 旬」「そろそろ 旬」「旬の じき」「えらびかた」。
- 書体は Android 標準のゴシック体、大きさと太さは Material 3 の文字スタイルを基本とする案。
- 説明は短く区切る。端末の文字サイズ設定を大きくしても、名前や説明が欠けないようにする。

## 一覧画面の案

買い物中に食材を見つけやすいよう、絵と名前を中心にする。

分類による切り替えや絞り込みは設けない。「いまが 旬」「そろそろ 旬」のそれぞれに、対象となる野菜・魚・果物をまとめて表示する。

1. アプリ名
2. 現在の月
3. 「いまが 旬」の見出しと食材一覧
4. 「そろそろ 旬」の見出しと食材一覧。「らいげつから」と添えて意味を伝える

食材カードは2列に並べる。「いまが 旬」と「そろそろ 旬」は見出しと配置で区別する。

食材をタップすると、その食材の詳細をモーダルボトムシートで下から開く。今月も来月も旬の食材は「いまが 旬」にまとめ、同じ食材を両方に載せない案。12月の来月は翌年1月として扱う。

## イラストの役割

色鉛筆のやわらかい線と塗りを採用する。最初の生成例は写実的すぎるとのフィードバックを受けたため、[ユーザー指定の参考画像](https://d2hq8z6bbc4zk8.cloudfront.net/wp-content/uploads/2018/03/29171507/a0e640674976cdf15f0a315420d7b07e-min.png)のような絵本寄りのタッチを目指す。

淡い色、白い紙目を残す塗り、丸く簡略化した形、少し揺れのある輪郭を基本にする。細かな葉脈・魚のうろこ・皮の質感や、強い陰影・光沢の描き込みを抑える。参考画像は絵柄の方向性を確認するためのもので、登場するキャラクターや場面を素材として使うものではない。

一覧と詳細では、目的に合わせて異なるイラストを使う。

- 一覧：食材を見つけるための図鑑風イラスト。本物の色や形、葉や皮などの特徴を残し、背景や飾りを省いて小さくても見分けやすくする。
- 詳細：選び方を説明するイラスト。店頭で注目する部分や状態を伝える構図にする。一覧の絵柄や構図にそろえることより、説明のわかりやすさを優先する。

詳細では一覧のイラストを大きく載せ直すことを必須にせず、選び方の説明図を中心にする。丸や矢印、部分の拡大などの使い方は、説明内容に合わせて検討する。

鉛筆の質感は、食材の形や色、選び方の注目箇所を見分けにくくしない範囲で使う。文字は画像に描き込まず、読みやすい UI の文字として表示する。HTML ラフには色鉛筆タッチの生成画像を反映する。一覧用の全体図と詳細用の説明図を別の画像として用意する。

## 詳細（モーダルボトムシート）の案

- 食材の名前
- 「えらびかた」：店頭で確認できるポイントを、選び方を説明するイラストと短いことばで伝える
- 「旬の じき」：旬の月を見られるようにする
- 閉じるボタン、背景タップ、下スワイプで閉じる操作。一覧のスクロール位置を保つ

選び方は承認済みの提供価値。具体的な説明・絵の点数や配置は未決定。

## 次に検討すること

- 分類をまとめた一覧での食材の並び順。野菜 → 魚 → 果物という優先順位をどう反映するか。
- 一覧の列数、絵の大きさ、色、文字、余白。
- 絵柄の見本と、選び方を絵で伝える方法。
- 各グループに該当する食材がない場合の表示。

この文書は画面構成の案であり、ビジュアルデザインやデザイン基盤の実装はまだ完了していない。

## 画面ラフ

[一覧・詳細の操作できる HTML ラフ](mockups/screens.html)。ローカルのブラウザで開き、食材を押すと詳細のモーダルボトムシートが下から開く。閉じるボタン、背景タップ、上部ハンドルの下スワイプ、Escape キーで閉じられ、一覧の位置を保つ。

暖色の主要色と2列の一覧を使った配置の検討用。一覧には色鉛筆タッチの全体図、詳細には注目箇所を示す別構図の説明図を配置している。図鑑風の絵・説明図は本番の完成イラストではない。11月固定の表示例で、旬・選び方の文章も検討用の仮データ。旬の判定処理や Android の Material 3 部品を実装したものではない。
